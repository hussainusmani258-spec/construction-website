# 🏗️ Construction Company Website

A clean, modern, and fully responsive frontend web template designed for construction companies, architecture firms, and engineering businesses. This project is built using vanilla **HTML5** and **CSS3** with a strong emphasis on modern layout techniques like Flexbox and CSS Grid.

---

## 🚀 Features

- **Responsive Navigation Bar**: Sticky/top-aligned header with brand logo and clean menu links.
- **Hero Section**: Full-screen (`100vh`) hero banner with a dark background gradient and prominent Call-to-Action (CTA) button.
- **Services Section**: 3-column layout showcasing core services with icons and descriptions.
- **Unique Features Grid**: Modern cards with image thumbnails and smooth hover states.
- **Interactive Project Gallery**: Side-by-side architecture showcase featuring a custom **Top-to-Bottom slide-in hover overlay effect** and a permanent text info card.
- **Statistics Counter Section**: 5-column vibrant yellow layout highlighting key company metrics (Projects Completed, Happy Clients, etc.).
- **Why Choose Us Section**: 6-box feature grid styled with Font Awesome icons.
- **Contact & Footer Section**: Fully styled two-column contact form and a professional dark mode footer with social links.

---

## 🛠️ Technologies Used

- **HTML5**: Semantic markup structure.
- **CSS3**: Modern styling, Flexbox, CSS Grid, media queries, and transition animations.
- **Font Awesome**: Icons for navigation arrows, contact forms, and features.
